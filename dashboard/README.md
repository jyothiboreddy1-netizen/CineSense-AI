# 📊 Power BI Dashboard

This folder contains the Power BI dashboard documentation for the CineSense AI project.

## Contents

- `PowerBi_dashboard.pdf` – Exported PDF version of the Power BI dashboard.

## Dashboard Features

The dashboard visualizes:

- Movie analytics
- Genre analysis
- Recommendation performance
- Evaluation metrics
- Movie insights and trends

## Note

The original `PowerBi_dashboard.pbix` file is **not included** in this repository because its size exceeds GitHub's recommended file upload limit. A PDF version is provided instead to showcase the dashboard design, visualizations, and analysis.The PBIX file can be shared separately upon request for academic or demonstration purposes.
